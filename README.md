# 小红书监控系统 (XHS Account Monitor v2.0)

> **平台支持**：目前仅完整适配并在 **Windows 10 / 11** 上实机验证，**macOS / Linux 暂未适配**。

只需使用一个**空白号（小号）**扫码登录，**无需关注目标账号、不产生任何点赞/评论/收藏等互动行为**，即可对目标小红书账号进行**悄无声息的只读静默监控**——涵盖 **本地全量存档、三态分层巡检、删帖/改文/新评时间对比、IP 与资料变更追踪、次日 0 点「昨天 HH:mm」精确时间对照汇总**，配套 Linear 极简风格本地 Web 控制台与 Bark / QQ 邮箱双通道提醒。

项目仅依赖 Node.js v24 原生能力（内置 TypeScript 执行与 `node:sqlite`）及极少量核心包，支持多账号独立数据隔离，并已通过 `.gitignore` 严格隔离本地隐私配置与抓取数据，可直接开源部署或上传 GitHub。

## 核心功能

1. **小号免关注 · 悄无声息静默监控**
   - 仅需准备一个**空白号（小号）**扫码登录即可监控任意目标小红书账号的公开主页动态，与日常大号完全隔离（独立登录态保存在本地 `storage/browser-profile/`）。
   - **全程无需关注对方**，也绝不执行点赞、收藏、评论、私信等任何写入/互动操作，纯只读浏览，不留互动痕迹，静默掌握账号动态变化。

2. **首次运行全量备份（解决超过 2 天丢失具体时分的问题）**
   - 首次填写目标主页链接后，自动抓取并保存账号现有全部笔记、高清原图、头像、正文以及全部历史评论与子回复。
   - 同时记录接口毫秒级时间戳与页面显示文本，并在每篇笔记目录下生成 `笔记图文信息备份.json`；即使超过 2 天小红书页面只显示 `MM-DD`，本地库仍永久保留精确发布时间与图文快照。
   - 针对仅 0–1 篇笔记的短页面做了异步加载等待与空基线防护，避免因网络波动误判为 0 篇笔记。

3. **三态分层监控 + 评论者小红书号缓存（更贴近真人浏览习惯）**
   - **轻量主页模式（默认随机 15–20 分钟）**：平时仅访问目标主页 1 页，即可监测名字/性别/签名/头像/IP、关注粉丝总赞藏、新发笔记、删帖、标题与点赞变化；若发现某篇变动（含 0 篇变 1 篇），当轮仅深入检查变动帖。
   - **定期全部笔记模式（默认随机 50–55 分钟）**：定时完整巡查全部笔记详情、评论与编辑时间；顶部提供 **「检查全部笔记」** 按钮随时手动触发。
   - **高频追踪模式（默认随机 5–10 分钟）**：检测到监控范围内的有效变动后自动切换，每轮精准检查「主页 + 变动帖 + 除变动帖外最新 4 篇」，连续 2 轮无新动静自动恢复常态。
   - **评论者小红书号防重查缓存**：启动采集前全量传入本地 `user_red_id_cache`，已有记录（含已标记查不到的账号）绝不重复访问对方主页，仅对全新评论者按需查询。

4. **全方位变动对比与多账号独立隔离**
   - **删帖 / 删评对比**：保留本地已抢救的原图与原文，并根据「最后确认存活时间 ~ 本次发现消失时间」自动推算大概删除时间区间与存活时长。
   - **改文与编辑时间记录**：记录笔记前后内容红绿 Diff 对比及平台留下的精确编辑时间（写入 `notes` 与 `note_revisions` 版本表）。
   - **新评论对比**：支持在超过 2 天的老笔记下出现新评论时，调取本地锁定的原笔记精确发布时间进行对比。
   - **账号资料与 IP 属地追踪**：自动记录 **IP 属地**（含主页与笔记级）、**头像**、**名字**、**性别**、**个性签名**（默认「还没有简介」等占位自动归一化为空白）的变更轨迹，同步写入 SQLite 与 `storage/logs/*.jsonl`。
   - **多账号切换完全隔离**：数据库全表按 `user_id` 分账存储（笔记、评论、动态、变动记录、IP/头像/资料历史、每日汇总与建档状态互不串台），随时切换目标账号不会继承旧账号数据，切回历史账号可无损续接监控且免重复建档。

5. **次日 0 点（默认 `00:02`）精确时间核对与每日汇总**
   - 利用小红书跨过零点后会将前一天内容显示为精确 **`昨天 HH:mm`**（及 `编辑于 昨天 HH:mm`）的机制，每天自动复核前一天所有新内容，将精确时间永久锁定至本地数据库，并与当天首次捕获时间对照输出 Markdown / JSON 日报至 `storage/reports/`。
   - 控制台顶部支持一键查看 **「当天汇总」**。

6. **Linear 风格本地 Web 控制台 + 双通道消息推送**
   - 本地访问 `http://localhost:3000`，支持明暗主题切换、独立实时倒计时卡片、作品详情抽屉、原图灯箱预览与快捷键（`1–5` 切换视图、`/` 搜索、`Esc` 关闭弹窗）。
   - 支持 **Bark（iOS 推送）** 与 **QQ 邮箱（原生 SMTPS `smtp.qq.com:465`，零额外依赖）** 双通道提醒，可同时开启或单独使用，并在设置页提供一键测试按钮。

## 快速开始（懒人一步到位）

### 环境要求
- **操作系统**：**Windows 10 / 11**（macOS / Linux 暂未适配）
- **Node.js `v24+`**（使用原生 TypeScript 执行与内置 `node:sqlite`，**必须 v24 及以上版本**）
- **浏览器**：本机已安装 **Google Chrome**（或 Windows 自带的 Microsoft Edge，系统会自动识别路径，**无需额外下载 Playwright 浏览器内核**）

---

### 第 1 步：安装 Node.js v24 LTS

1. 打开 Node.js 官方下载页：https://nodejs.org/zh-cn/download
2. 参照下图红框操作：右上角版本选择 **`v24.x (LTS)`**，然后点击下方绿色按钮 **`Windows 安装程序(.msi)`** 下载安装包。
3. 双击 `.msi` 安装包，保持默认选项一路点击 **Next** 完成安装。

![Node.js v24 LTS 下载指引](docs/images/node.js.png)

4. 验证安装成功：按 `Win + R` 输入 `cmd` 回车，输入以下命令并回车，看到 `v24.x.x` 即表示环境就绪：
   ```bash
   node -v
   ```

---

### 第 2 步：下载项目并安装依赖

1. 在本仓库页面点击右上角绿色 **`Code`** → **`Download ZIP`** 下载压缩包并解压到任意目录（例如 `D:\xhs-account-monitor`），或使用 `git clone` 拉取代码。
2. 进入解压后的项目根目录，点击文件资源管理器顶部的**地址栏**，直接输入 `cmd` 并按回车打开命令行窗口。
3. 执行以下命令安装项目依赖（仅含 `hono`、`@hono/node-server`、`playwright-core` 等轻量依赖，几十秒即可完成）：
   ```bash
   npm install
   ```
   > **国内网络加速**：如果上面安装较慢，可直接使用国内镜像源：
   > ```bash
   > npm install --registry=https://registry.npmmirror.com
   > ```
   > *注：项目复用本机已安装的 Chrome / Edge，**不需要**执行 `npx playwright install`。*

---

### 第 3 步：用空白号（小号）扫码登录小红书

1. 双击项目根目录下的 **`扫码登录小红书.bat`**（或在命令行运行 `npm run login`）。
2. 在弹出的浏览器窗口中，使用你的**空白号（小号）**扫码登录小红书（**无需关注目标账号**，仅用于只读访问页面）。
3. 看到提示登录成功后，直接关闭弹出的浏览器窗口即可，登录态会自动保存至本地 `storage/browser-profile/`，与常用大号互不影响。

---

### 第 4 步：启动监控并配置目标与提醒

1. 双击项目根目录下的 **`启动监控系统.bat`**（或在命令行运行 `npm start`），保持黑色运行窗口开启，浏览器会自动打开控制台 **`http://localhost:3000`**。
2. 在左侧进入 **「设置」** 页面，按需填写：
   - **主页链接（必填）**：在网页版小红书打开目标账号主页，复制浏览器地址栏完整链接粘贴即可。
   - **手机推送 Bark（选填，iOS 推荐）**：手机安装 Bark App，粘贴「服务器」页的测试链接或 22 位 Key，点击 **「测试推送」** 验证。
   - **QQ 邮箱通知（选填，全平台通用）**：填入你的 QQ 号或 QQ 邮箱，再填入 **16 位 SMTP 授权码**（在 QQ 邮箱网页版「设置 → 账户」开启 `POP3/SMTP 服务` 获取，**非 QQ 登录密码**），点击 **「测试邮件」** 验证。
3. 点击右下角 **「保存设置」**，系统将立即自动完成首次全量存档，随后进入三态分层静默监控！

<details>
<summary>常见问题排查（点击展开）</summary>

- **输入 `node -v` 提示“不是内部或外部命令”**：安装完 Node.js 后需要**重新打开**一个新的 `cmd` 窗口再执行；若仍不行，重新运行 `.msi` 安装包并确认勾选了 `Add to PATH`。
- **提示端口 `3000` 被占用**：说明监控系统已经在后台运行，直接用浏览器访问 `http://localhost:3000` 即可。
- **启动后提示找不到 Chrome**：进入设置页最下方的 **「Chrome 路径」**，手动填入你电脑里 `chrome.exe` 或 `msedge.exe` 的完整路径后保存即可。

</details>
